There are $n$ choices for the first item. Then $n-1$ for the second item, after the first has been chosen and removed from the set of possibilities. Then $n-2$ for the third, then ..., then $n-r+1$ for the $r^\text{th}$ item. So the total number of possibilities is the product:

$$
n(n-1)(n-2)\cdots(n-r+1)
$$

We can express this with factorials using a technical observation:

$$
\begin{gather*}
\frac{n!}{(n-r)!} \;=\; \frac{n(n-1)(n-2)\cdots(n-r+1)(n-r)(n-r-1)\cdots 1}{\phantom{n(n-1)(n-2)\cdots(n-r+1)}(n-r)(n-r-1)\cdots 1}\\\\ \quad \gg\gg \quad n(n-1)(n-2)\cdots(n-r+1)
\end{gather*}
$$
