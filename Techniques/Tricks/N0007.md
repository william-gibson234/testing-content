An alternative to integrating and differentiating the CDF directly is to change variables using differentials.

The measure for integration is $f_X(x)\,dx$.

For example, set $Y=X^2$ so $dy=2x\,dx$ and $dx=\frac{1}{2\sqrt{y}}\,dy$.

Thus $f_X(x)\,dx \;=\; f_X(\sqrt{y})\frac{1}{2\sqrt{y}}\,dy$.

So the measure of integration in terms of $y$ is $f_Y(y)\;=\; f_X(\sqrt{y})\frac{1}{2\sqrt{y}}$.

Warning: this assumes the function is one-to-one.
