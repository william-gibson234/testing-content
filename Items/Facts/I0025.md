---
long_title: the cdf of a discrete random variable is a step function with jumps equal to pmf values
short_title: cdf step function
type: item
subtype: fact
keywords:
  - cdf
  - discrete rv
  - pmf
  - step function
---

The CDF of a discrete RV is always a stepwise increasing function. At each step up, the jump size matches the PMF value there.
