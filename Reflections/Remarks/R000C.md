Notice that ${5\choose 3,2}={5\choose 3}$, so we have already defined these values (i.e. with $k=2$) when we defined binomial coefficients. But when $k>2$, the formula gives new values. They correspond to the coefficients in multinomial expansions. For example, $k=3$ gives the coefficients for $(x+y+z)^n$.
